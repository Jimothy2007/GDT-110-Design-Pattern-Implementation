How to run:
- Clone the repository to GitHub desktop.
- Select add project from disk on the Unity Hub.
- Open the project and press run.

Controls:
- Hold 'A' and 'D' to move left and right
- Press 'Space' to jump, Hold 'Space' to jump higher
- Press 'J' to melee attack, Hold 'W' while attacking to attack up, Hold 'S' while attacking and in the air to attack down
- Press 'K' to gun attack, Hold the movement keys while shooting to change the angle
